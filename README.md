# EGS-MUSICWORLD

Клиентский мод для одиночной игры в **Empyrion – Galactic Survival**, в том числе для сценария **Reforged Eden 2**. На одной и той же планете можно услышать разные темы. Между ними остаются паузы для ветра, шагов и звуков базы. Когда игра включает боевую музыку, мод плавно переключается на боевой плейлист.

[Скачать сборку 0.1.0 для Windows](https://github.com/Tefoke1/EGS-MUSICWORLD/raw/refs/heads/main/dist/EGS-MUSICWORLD-0.1.0.zip)

## Установка

1. Закрой Empyrion, распакуй архив в отдельную папку и запусти **Install.cmd** обычным двойным щелчком. Установщик найдёт игру в библиотеках Steam. Если игра стоит отдельно, передай путь аргументом, например `Install.cmd -GamePath "D:\Games\Empyrion"`.
2. Запусти Empyrion в режиме с выключенным **Easy Anti-Cheat** для клиентских модов и загрузи своё одиночное сохранение.
3. Выйди на поверхность. По умолчанию играют шесть тем для исследования и четыре для боя. Первый трек начинается после загрузки игры. При входе в бой новая музыка может прервать тихую паузу.

Установщик кладёт мод в `Content/Mods/MusicWorld` внутри игры. При повторной установке сохраняются твои настройки и треки. Для удаления закрой игру и убери папку `MusicWorld` из `Content/Mods`. Если там твоя музыка, перенеси папку целиком.

## Своя музыка

Положи файлы **MP3, OGG Vorbis или WAV** в папку нужного режима и загрузи сохранение заново.

| Папка внутри `Content/Mods/MusicWorld` | Когда звучит |
| --- | --- |
| `Music/Exploration/` | Прогулки, строительство, исследование и спокойный полёт |
| `Music/Combat/` | Наземный или космический бой, когда игра запускает боевой саундтрек |

У каждого режима свой выбор. Пустая папка включает подборку из установленных ресурсов Empyrion. Если в папке есть подходящие файлы, проигрываются они. Каждый трек попадает в очередь один раз за круг, порядок перемешивается. Если файл не читается, мод пропускает его. Если недоступна вся пользовательская подборка, включаются встроенные темы.

## Настройки

Открой `musicworld.json` **в установленной папке мода**. Новые значения действуют при следующей загрузке сохранения.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `volume` | 0.40 | Громкость музыки мода от 0 до 1 |
| `fadeSeconds` | 2 | Время плавного перехода в секундах |
| `exploreGapMin`, `exploreGapMax` | 25, 75 | Диапазон тишины между спокойными треками |
| `combatHold` | 3 | Сколько секунд сохранять боевой режим при коротком перерыве в штатной боевой музыке |
| `afterCombatQuiet` | 12 | Задержка до начала спокойной музыки после выхода из боевого режима |
| `debugLog` | false | Записывать режим и название выбранного трека в клиентский журнал Empyrion |

## Совместимость и проверка

Первая сборка скомпилирована с клиентскими библиотеками **Empyrion 1.20.1, build 5232**, Windows. Мод использует клиентский API Eleon и наблюдает за отдельным аудиоисточником боя. Для переключения требуется, чтобы игра сама запустила боевую тему. Мод управляет музыкой в одиночной игре и восстанавливает заглушённые им источники при выходе. Игровой профиль, сценарий и сохранения установщику не нужны.

Автоматическая проверка воспроизводит вход и выход из боя, перекрытие двух треков, тихие интервалы, паузу, плохой аудиофайл и возврат штатных источников. В этой версии переходы проверены на модели аудиосистемы. Проверка на слух в реальной игре ещё предстоит. Для неё включи `debugLog`, загрузи сохранение, дождись фоновой темы, вступи в бой и выйди из него. В клиентском журнале появятся записи `MusicWorld`, затем `Mode: Combat` и `Mode: Exploration`.

## Сборка из исходников

В Windows PowerShell выполни в корне репозитория.

~~~powershell
.\Build.ps1 -GamePath 'E:\Steam\steamapps\common\Empyrion - Galactic Survival'
.\tests\Run.ps1
.\tools\Package.ps1
~~~

Компилятор C# входит в .NET Framework для Windows. Сборка берёт API и Unity DLL из установленной игры. Результат лежит в `build/MusicWorld.dll`, установочный архив в `dist/`, временные файлы в `.work/`.
